# Telegram bot

Минимальный Telegram-бот на Node.js: отвечает `Hello, world!` на каждое текстовое сообщение.

## Запуск

1. Установите зависимости: `npm install`.
2. Добавьте токен бота в `BOT_TOKEN` в файле `.env`.
3. Для разработки запустите `npm run dev` (nodemon перезапускает бота при изменениях).
4. Для обычного запуска используйте `npm start`.

Токен можно получить у [@BotFather](https://t.me/BotFather). Файл `.env` исключён из Git.

## Структура

- `src/index.js` — точка входа и запуск Telegram-бота.
- `src/controllers/` — обработка входящих сообщений.
- `src/services/` — общая логика бота и небольшие сервисы функций.
- `data/` — место для данных и конфигурации.
